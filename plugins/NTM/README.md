# No Tap Mention

Tap a message author's name without inserting a mention or opening their profile. Avatar taps and long presses stay unchanged.

Version **1.0.0**, stable release.

Add this URL in **Valenced → Plugins → Advanced**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-plugins-test/main/index.json
```

Install from **latest**, enable and restart Discord. Existing beta users should switch to **latest** for stable updates. Disable Tap to Profile if installed. No settings, stored data or network requests.
